# Agent Workbench

本项目是一个本地优先的多 Agent 企业自动化平台，适合课程展示、简历项目和面试演示。

## 直接运行

双击：

`index.html`

不需要安装依赖，不需要启动后端，不需要 API Key。

## 第一次打开怎么用

推荐先点首页顶部的：

`一键演示完整项目`

然后再点击首页的预设任务卡片，例如：

- 演示企业知识库
- 演示代码审查
- 演示数据分析
- 演示求职包装
- 演示工作流编排
- 打开超级工具箱
- 打开全能工作台
- 打开实用应用
- 成绩分析演示
- 综合管理套件
- 项目写进简历

## 项目包含什么

- 统一 Agent 控制台
- Agent 编排中心
- 项目简历页
- 知识库 RAG Agent
- 代码 Review Agent
- CSV 数据分析 Agent
- 求职 JD 匹配 Agent
- 市场研究报告 Agent
- 超级工具箱：会议纪要、邮件、任务拆解、周报、Prompt、风险检查、用户故事、API 方案、测试用例、学习路线、PRD 和导出中心
- 全能工作台：覆盖生活、生产、求职、学习、数据、文档和网页信息整合
- 数据记录与分析：支持本地记录、趋势图、统计分析和下一期预测
- 实用应用：任务看板、习惯打卡、收支账本、目标进度、Markdown 笔记、番茄钟、JSON/CSV 工具
- 成绩分析平台：支持上万学生、多班级、多课程、自定义记分项目、自定义权重、多图表对比、历史记录和 Excel 友好导出
- 文档知识库：支持文本文件上传、文本切分、问答接口演示、引用来源、问答历史、多文件管理、登录/权限/多用户模拟
- 综合管理套件：CRM、库存、项目里程碑、日历事件、自动化规则、经营报表、安全审计、API Mock、备份恢复
- Trace 评估观测面板
- 可选 OpenAI API Key 接入

## 文件说明

核心运行文件：

- `index.html`：项目入口
- `styles.css`：页面样式
- `app.js`：核心逻辑

说明文档：

- `使用指南.md`：告诉你如何演示和使用项目
- `项目说明书.md`：适合课程报告、答辩和项目介绍
- `简历与面试材料.md`：适合写简历、准备面试讲解

## 简历推荐写法

项目名称：

`Agent Workbench：本地优先的多 Agent 企业自动化平台`

简历 bullet：

- 独立开发 Agent Workbench 多 Agent 平台，集成 RAG 问答、代码 Review、CSV 数据分析、JD 匹配、研究报告和 Trace 观测，支持浏览器本地一键运行。
- 设计 Agent Router 与工作流编排模块，将 Planner、Retriever、Tool Executor、Evaluator 串联为可解释任务链。
- 实现本地检索、置信度评分、引用来源、规则扫描、数据可视化和失败回退机制，并通过一键演示和预设任务提升项目展示体验。

## 项目亮点

- 打开即用：双击 HTML 即可运行。
- 演示友好：有一键演示和预设任务。
- 功能完整：覆盖多个 AI Agent 应用场景。
- 工具丰富：内置 12 个项目管理和求职展示工具。
- 场景全面：生活管理、学习计划、求职材料、文档处理、数据分析都能用。
- 可长期使用：不只是生成文本，还能记录任务、习惯、账本、目标和笔记。
- 数据分析强：成绩平台支持条形图、柱状图、折线图、饼图、雷达图、热力图。
- 工程化：包含路由、工作流、Trace、置信度和失败回退。
- 可扩展：内置云部署说明，后续可升级后端、数据库、对象存储和真实登录系统。
- 系统感更强：新增企业管理类模块，适合展示复杂业务系统设计。
- 求职导向：内置简历材料和面试讲法。
